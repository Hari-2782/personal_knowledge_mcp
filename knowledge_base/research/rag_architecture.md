
# Retrieval Augmented Generation Architecture

RAG combines information retrieval with large language
model generation.

## Main Components

1. Document ingestion
2. Text extraction
3. Chunking
4. Embedding generation
5. Vector database
6. Similarity search
7. Context construction
8. LLM response generation

## Benefits

RAG allows an LLM to use external knowledge without
requiring model fine-tuning for every knowledge update.

## Challenges

- Retrieval accuracy
- Chunk size optimization
- Embedding quality
- Context window limitations
- Retrieval latency
