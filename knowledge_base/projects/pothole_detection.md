
# Real-Time Pothole Detection

This project uses computer vision to detect road hazards
from dashcam images and video.

## Technologies

- Python
- YOLOv8
- OpenCV
- Kalman filtering
- Fast-SCNN

## System Components

1. Road surface anomaly detection
2. Road sign detection
3. Temporal validation
4. Risk assessment
5. GPS-based hazard visualization

## Objective

Improve road safety through vision-based road monitoring.
